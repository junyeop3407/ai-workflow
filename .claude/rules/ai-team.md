# AI 팀 운영 규칙 (모델 배정 · 리뷰 시점 · 외부 AI)

Claude Code는 지휘자다. 일을 나누고, 맞는 직원(모델·외부 AI)에게 맡기고, 결과를 모아 정리해서 보고한다.
사용자가 모델이나 도구를 따로 말하지 않아도 이 규칙대로 스스로 고른다.

---

## 1. 모델 배정 규칙 (서브에이전트)

서브에이전트를 부를 때는 반드시 `model`을 직접 지정한다. 지정하지 않고 메인 모델을 물려받게 하지 않는다.

| 일의 종류 | 모델 | 예시 |
|---|---|---|
| 판단 · 설계 · 지휘 | `opus` | 기획, 아키텍처 설계, DB 구조 설계, 보안 설계, 3번 넘게 막힌 버그 원인 분석 |
| 실무 구현 | `sonnet` | 화면·컴포넌트 구현, API 작성, 기능 추가, 리팩터링, 문서 작성 |
| 반복 · 검증 | `haiku` | 파일·코드 찾기, 테스트 실행, 린트·빌드 확인, 단순 수정, 결과 요약 |

- 애매하면 `sonnet`을 고른다.
- `opus`는 정말 판단이 필요한 일에만 쓴다. (Pro 요금제 한도 절약)
- 같은 일을 `haiku`로 해 봤는데 2번 실패하면 `sonnet`으로 올린다. `sonnet`이 2번 실패하면 `opus`로 올린다.
- `.claude/agents/` 의 에이전트 파일에도 위 표에 맞게 `model:` 값을 적어 둔다.
  - 예외: `red-team`(보안 공격 테스트)은 공격 방법을 스스로 판단해야 해서 `sonnet`을 쓴다.

## 2. 외부 AI 직원

### 코덱스 (OpenAI) — 코드 리뷰 · 막힌 일 대신 처리 · 이미지 생성
- 공식 플러그인 `codex@openai-codex` 로 연결한다.
- 이미지(게임 스프라이트, 아이콘, 앱 일러스트, 배경)가 필요하면 `codex exec "..."` 로 GPT에게 만들게 한다.

### 안티그래비티 (Gemini) — 2차 검토 · 영상/스크린샷 분석 · 구글 연동
- 안티그래비티는 `agy -p "..."` 로 불러서 쓴다.
- 오래 걸릴 수 있는 일은 `--print-timeout 5m` 을 붙인다.
- 이런 때 쓴다:
  - UI 스크린샷을 보여주고 디자인·사용성 2차 검토
  - 게임 플레이 녹화 영상, 유튜브 영상 분석
  - 기획서·README·제안서 2차 검토
- 결과는 그대로 붙이지 않는다. 내 작업과 비교해서 맞는 점, 다른 점, 반영할 점으로 정리한다.

### 공통
- 외부 AI 결과와 Claude 판단이 다르면 둘 다 보여주고, 어느 쪽을 택했는지와 이유를 적는다.
- 외부 AI에게 비밀번호, API 키, `.env` 내용, 개인정보를 보내지 않는다.
- 외부 AI 호출이 실패하거나 응답이 비면 1번만 다시 시도하고, 그래도 안 되면 건너뛰고 보고에 적는다. 무한 재시도 금지.

## 3. 리뷰 시점 규칙

| 시점 | 할 일 |
|---|---|
| 기능 하나가 끝났을 때 | `/codex:review --background` 실행 → 다음 작업 진행 → `/codex:result` 로 결과 확인 후 반영 |
| UI 화면을 새로 만들었을 때 | 스크린샷을 찍어 `agy -p` 로 2차 검토 |
| 같은 버그에서 3번 넘게 막혔을 때 | `/codex:rescue --background` 로 코덱스에게 넘긴다 |
| 완성도 90%를 넘겨서 배포하기 전 | `/codex:adversarial-review` 1번 + 기존 레드팀 단계 + `agy -p` 로 기획 대비 빠진 기능 확인 |

### 금지
- 코덱스 리뷰 게이트(`--enable-review-gate`)는 켜지 않는다.
  - 이유: Claude가 응답을 끝낼 때마다 코덱스 리뷰가 자동으로 돌고, 문제가 나오면 끝내지 못하게 막는다.
    자동 루프(완성도 90%까지 반복)와 겹치면 루프 횟수 × 리뷰 횟수만큼 Claude와 코덱스 한도가 둘 다 빨리 닳는다.
- 코덱스 리뷰를 응답마다, 파일 하나 고칠 때마다 돌리지 않는다. 위 표의 시점에만 돌린다.
- 리뷰에서 나온 사소한 지적(취향 차이, 이름 짓기 등)은 바로 고치지 않고 모아 두었다가 마지막에 한 번에 정리한다. 버그·보안 지적만 즉시 고친다.
